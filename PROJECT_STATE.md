## Canonical lifecycle

Intent
-> Translation (ATL)
-> Planning
-> Execution
-> Validation
-> Observation
-> Memory
-> Next Intent

ACL-001 is canonical as an architectural specification. Implementation alignment is proven only where executable evidence exists.
